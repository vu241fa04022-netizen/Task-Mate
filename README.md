# TaskMate

TaskMate is a frontend-only productivity workspace for organizing everyday tasks. It runs in the browser and stores tasks and preferences in `localStorage`; no account, backend, database, or API is used.

## Features

- Overview dashboard with task totals, completion progress, weekly productivity chart, recent tasks, and upcoming due dates.
- Create, edit, complete, search, filter, and delete tasks with category, priority, description, and due date.
- Monthly calendar with previous/next navigation, today highlighting, and task creation directly from a date.
- College, Personal, Work, and Other category summaries.
- Light and dark themes, editable display name, profile visibility, and local data reset.
- Responsive sidebar, mobile task/calendar layouts, validation, and action notifications.
- Sample tasks are added the first time the app is opened.

## Technologies

- React and JavaScript
- Vite
- Modern CSS
- Lucide React
- Recharts
- Browser `localStorage`

## Installation

Requirements: Node.js 20.19+ or 22.12+.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`.
